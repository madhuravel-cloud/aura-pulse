WELCOME TO AURA PULSE

01

Prerequisites

  • Active System Playback Source: Keep an active default playback device (such as Laptop Speakers) set in Windows so Aura Pulse can capture loopback audio cleanly.
  • Pre-Paired Audio Endpoints: Pair and connect your target headphones or speakers in Windows Bluetooth & Sound settings before starting a session.
  • Bluetooth LE Audio (LC3): Enable Use LE Audio when available in Windows Bluetooth settings and use two LE Audio-capable headsets for dual wireless streaming over one built-in radio.
02

If LE Audio Is Not Supported

  • Bluetooth + Wired / USB Hybrid: Stream simultaneously to one Classic Bluetooth headphone alongside a 3.5mm wired headset, USB headset, or HDMI display speaker.
  • USB Bluetooth Audio Transmitter: Connect a USB Bluetooth audio adapter for the second headset—Windows treats it as an independent USB sound card, bypassing the single-A2DP driver cap.
  • Hands-Free Profile Fallback: Run one headset on Stereo (A2DP) and select the second headset's Hands-Free AG Audio endpoint for voice or lecture playback.
